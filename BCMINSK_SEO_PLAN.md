## Блокеры / решения, нужные от владельца

- **Метро как структурное поле — В ПРОЦЕССЕ (2026-09-06), владелец
  подключает 2GIS API в параллельной ветке.** Формат ответа 2GIS
  (`nearest_stations`), который владелец прислал, уже согласован как схема
  для нового поля — см. запись в журнале CLAUDE.md от 2026-09-06 про
  `nearest_metro_stations`. Свободный текст `metro` НЕ заменяется —
  остаётся как есть (часть значений — куратированные веб-архивами
  Яндекс.Карт с реальным временем пешком, не только метрами по прямой,
  терять это нельзя), новое структурное поле — рядом, для честного
  "N м по прямой" и для будущих метро-хабов, когда данные по всем БЦ
  будут собраны. Домен `catalog.api.2gis.com`/`.ru` ДОСТУПЕН из песочницы
  этой сессии (проверено curl'ом, `2gis.by` сам сайт — нет, как и
  Яндекс.Карты) — если у владельца есть рабочий API-ключ, эту сессию тоже
  можно подключить к сбору данных, не только параллельную ветку.
- **Описание в прозе (300-600 слов) на карточке** — приоритет 1 пункт 1
  для карточки, но требует настоящего ресерча по каждому БЦ (история,
  архитектура, для кого подходит), чтобы не быть шаблонным текстом
  (ровно то, от чего сам документ предостерегает — "не 'портал
  предлагает', а полезное"). У исходных 27 уже ЕСТЬ насыщенные
  `highlights` (история/арендаторы/награды из ресерча) — для НИХ описание
  можно частично собрать из уже добытых фактов. Для новых 118 (только из
  prometr.by, без ресерча) — писать текст не из чего, кроме структурных
  полей (адрес/класс/площадь) — риск получить именно тот шаблонный текст,
  которого нужно избегать. **Спросить владельца перед стартом**: делать ли
  масштабный ресерч по 118 зданиям (много сессий), или ограничиться
  честным кратким автосоставленным абзацем из структурных полей без
  претензии на «300-600 слов редакционного текста».
- ~~**Дерево хаб-URL по пересечениям параметров**~~ — класс×район сделаны
  2026-09-06 (см. "Что уже сделано" выше). Класс×метро/район×метро — ждут
  метро-поля (см. пункт выше).
- **Ставки аренды** — структурных данных по ставкам на уровне каталога нет
