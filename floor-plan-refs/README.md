# Планировки — сырьё для перерисовки

Черновые планировки этажей бизнес-центров, скачанные с prometr.by в процессе
обогащения каталога `/minsk/bcminsk` (см. журнал в CLAUDE.md). Изображения — с
водяным знаком prometr.by, не для публикации как есть. Владелец планирует
отрисовать их заново без водяных знаков — здесь просто сохранён источник,
чтобы не пришлось искать заново.

Не часть сборки (как и `examples/` рядом) — ничего отсюда не импортируется в
код и не публикуется на сайте.

Структура: `<slug-бизнес-центра>/floor-<этаж>.jpg`. Названия папок совпадают
со slug'ами в таблице `business_centers` на момент сбора (сентябрь 2026).
